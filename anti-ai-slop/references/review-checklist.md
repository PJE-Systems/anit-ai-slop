# Anti-AI-Slop Audit Checklist

## Identity

- [ ] Business is identifiable from the design/content
- [ ] Visual decisions relate to the business
- [ ] Existing brand assets are respected
- [ ] Page does not feel interchangeable

## Hero

- [ ] Clear business proposition
- [ ] Specific headline
- [ ] Useful CTA
- [ ] No unnecessary decorative clutter

## Layout

- [ ] Not every section is a card grid
- [ ] Not everything is centered
- [ ] Section compositions vary intentionally
- [ ] Content determines structure

## Visuals

- [ ] No unnecessary gradient blobs
- [ ] No unnecessary glassmorphism
- [ ] No generic neon effects
- [ ] No random 3D objects
- [ ] No fake dashboards
- [ ] No fake terminals
- [ ] Imagery is relevant

## Copy

- [ ] No filler
- [ ] No vague marketing paragraphs
- [ ] Claims are real
- [ ] No fabricated social proof

## Motion

- [ ] Animation has a reason
- [ ] No automatic fade-up everywhere
- [ ] No unnecessary parallax
- [ ] 3D is justified
- [ ] Reduced motion works

## UX

- [ ] Primary action is obvious
- [ ] Forms are appropriately short
- [ ] Mobile is intentionally designed
- [ ] Keyboard/focus basics work
- [ ] Content remains usable without animation

## Code

- [ ] No unnecessary dependencies
- [ ] No over-engineered abstraction
- [ ] Existing architecture respected
- [ ] Performance is acceptable

## Final question

> Could a generic AI website generator produce this same result by changing only the logo, colors and text?

If yes, keep redesigning.
