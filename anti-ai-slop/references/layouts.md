# Layout Patterns

Do not default to the standard AI landing-page sequence.

Useful alternatives:

- editorial
- asymmetric
- split-screen
- image-led
- narrative
- timeline
- map-driven
- process-driven
- product-led
- typography-led
- spatial/cinematic

Content should determine structure.

If several consecutive sections use "heading + paragraph + 3 cards", redesign the composition.
