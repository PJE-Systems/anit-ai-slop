# UX Review

A distinctive interface still needs to be easy to use.

Check:

- information hierarchy
- navigation
- CTA clarity
- form friction
- readability
- mobile interaction
- loading
- error states
- accessibility

For service businesses, users usually want to know:

1. What do you offer?
2. Can you help me?
3. How does it work?
4. Why should I trust you?
5. How do I contact you?

Design around these questions rather than around generic landing-page conventions.
