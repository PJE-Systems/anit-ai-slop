# Typography

Typography should establish hierarchy and character.

Avoid:

- oversized headings with no information
- excessive bold text
- centered text everywhere
- too many font families
- decorative type that harms readability

Prefer:

- clear hierarchy
- controlled line length
- deliberate spacing
- meaningful labels
- strong display/body contrast when appropriate

Do not enlarge weak copy to make it feel important. Improve the copy first.
