# Premium Service Business Example

## Generic approach

- giant centered heading
- blue/purple gradient
- abstract glowing map
- six service cards
- fake partner logos
- generic testimonials
- "fast, reliable, innovative" copy
- animated counters

## Anti-slop approach

Start from the actual business model.

If the company coordinates local providers:

- make coordination the visual concept
- show the relationship between customer, central coordinator and local provider
- use geography or movement if relevant
- show actual service categories
- explain the real process
- use verified network information only
- use a clear CTA

The visual system should communicate the business rather than merely look modern.

## Cinematic combination

If a cinematic story strengthens the concept:

Vehicle problem -> standstill -> central coordination -> nationwide network -> local partner -> assistance -> journey continues.

Combine with `cinematic-web-motion` when appropriate.
